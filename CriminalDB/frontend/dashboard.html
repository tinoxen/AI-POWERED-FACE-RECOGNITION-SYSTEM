Operator Guide & Overview

Welcome to the **CriminalDB Terminal**, the core biometric database system.

* Use the **Face Search** portal to match uploaded mugshots against stored records in the system database using SFace and YuNet AI model matching.
* Use **View Records** to search, edit, or delete criminal files using their standard information parameters. * Register new criminal profiles using **Add Person**. Secure activity logs are saved for auditing purposes.
